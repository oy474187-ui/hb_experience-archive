# HB Experience Archive

작업 과정과 결과물을 Finder를 탐색하듯 살펴볼 수 있도록 만든  
인터랙티브 웹 포트폴리오입니다.

### Live Demo
👉 [Experience Archive 바로가기](https://oy474187-ui.github.io/hb_experience-archive/)

---

## Overview

디자인 결과물뿐 아니라 문제를 발견하고,
직접 설계하고 구현해 온 과정을 하나의 아카이브로 구성했습니다.

Finder의 탐색 경험을 모티브로,
폴더를 열어보듯 프로젝트와 작업 기록을 살펴볼 수 있도록
웹 인터페이스를 직접 디자인하고 구현했습니다.
